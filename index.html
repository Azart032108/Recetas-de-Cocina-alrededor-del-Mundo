Introducción

Este documento quiere hacer ver distintas variables a partir de las recetas de cocina alrededor del mundo.

Tabla de Datos

Código 
# Tabla de datos de recetas, name, area y category
Recipes |> 
  select(name, area, category) |>
  datatable(
  options = list(
    pageLength = 5,
    language = list(url = '//cdn.datatables.net/plug-ins/1.10.11/i18n/Spanish.json')
  )
)

En esta tabla se muestra los nombres de las recetas, el lugar de donde vienen y su categoria.

Gráfico 1- Área x Categoría

Código 
data_pais <- Recipes |>
  count(area)

grafico <- data_pais |>
  ggplot(aes(
    x = reorder(area, n),
    y = n,
    fill = area
  )) +
  geom_col() +
  coord_flip() +
  theme_solarized()

grafico

Gráfico Interactivo 1 - Área x Categoría

Código 
data_pais <- Recipes |>
  count(area)

grafico <- data_pais |>
  ggplot(aes(
    x = reorder(area, n),
    y = n,
    fill = area,
    text = paste("Área:", area, "<br>Cantidad:", n)
  )) +
  geom_col() +
  coord_flip() +
  theme_solarized()

ggplotly(grafico, tooltip = "text") |>
  config(locale = "es")

grafico <- Recipes |>

    color = category
  )) +
  geom_point(size = 3) +
  theme_solarized() +
  theme(
    axis.text.x = element_text(size = 6.5, angle = 45, hjust = 1)

Gráfico 3, Pastel, Categorías y Cantidad en India.

Código 
# Gráfico de pastel interactivo

datos_pie <- Recipes |>
  filter(area == "Indian") |>
  count(category)

plot_ly(
  data = datos_pie,
  labels = ~category,
  values = ~n,
  type = "pie",
  textinfo = "label+percent",
  hoverinfo = "label+value+percent"
) |>
  layout(title = "Cantidad de recetas en India por categoría") |>
  config(locale = "es")
